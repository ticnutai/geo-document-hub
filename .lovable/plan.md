

# תוכנית בניית מערכת GIS מתקדמת

## סקירה כללית
בניית מערכת GIS אינטראקטיבית עם מפה, ניהול שכבות מידע, ניהול מסמכים וקבצים, וחיבור ל-GitHub.

## מבנה טכני

### 1. מפה אינטראקטיבית (Leaflet)
- שימוש בספריית **Leaflet** (חינמית, קוד פתוח) עם **react-leaflet**
- מפת בסיס OpenStreetMap + אפשרות לוויין
- כלי ציור על המפה (נקודות, קווים, פוליגונים)
- חיפוש מיקום (geocoding)

### 2. ניהול שכבות (Layers)
- פאנל צד לניהול שכבות מידע
- הוספת/הסרת שכבות GeoJSON
- שליטה בנראות ושקיפות
- קבוצות שכבות לפי קטגוריות

### 3. ניהול מסמכים וקבצים
- העלאת קבצים (PDF, תמונות, GeoJSON, Shapefile, Excel/CSV)
- חיבור מסמכים לנקודות/אזורים על המפה
- תצוגת רשימה וחיפוש קבצים
- תצוגה מקדימה של קבצים

### 4. חיבור GitHub
- ייבוא קבצי GeoJSON ומסמכים ישירות מ-GitHub repo
- סנכרון דו-כיווני דרך חיבור GitHub של Lovable
- ארגון קבצים בתיקיות לפי פרויקט/שכבה

## מבנה קבצים

```text
src/
├── pages/
│   └── Index.tsx          # דף ראשי עם מפה
├── components/
│   ├── map/
│   │   ├── MapView.tsx         # קומפוננטת מפה ראשית
│   │   ├── MapControls.tsx     # כלי שליטה
│   │   ├── DrawTools.tsx       # כלי ציור
│   │   └── LayerPanel.tsx      # פאנל שכבות
│   ├── documents/
│   │   ├── DocumentPanel.tsx   # פאנל מסמכים
│   │   ├── FileUploader.tsx    # העלאת קבצים
│   │   └── FilePreview.tsx     # תצוגה מקדימה
│   ├── sidebar/
│   │   └── AppSidebar.tsx      # סרגל צד ראשי
│   └── layout/
│       └── AppLayout.tsx       # מבנה כללי
├── hooks/
│   ├── useMap.ts              # לוגיקת מפה
│   └── useLayers.ts           # ניהול שכבות
├── types/
│   └── gis.ts                 # טיפוסים
└── data/
    └── sample-layers.ts       # שכבות לדוגמה
```

## ספריות נדרשות
- `leaflet` + `react-leaflet` - מפה
- `@types/leaflet` - טיפוסים
- `leaflet-draw` - כלי ציור (אופציונלי)

## שלבי בנייה
1. התקנת ספריות מפה ובניית layout בסיסי עם sidebar
2. בניית מפה אינטראקטיבית עם שכבות בסיס
3. פאנל שכבות עם אפשרות הוספה/הסרה
4. מודול ניהול מסמכים עם העלאה וחיבור למפה
5. כלי ציור ועריכה על המפה

## הערה לגבי GitHub
הפרויקט הזה ב-Lovable תומך בסנכרון ל-GitHub. ברגע שתחבר את הריפו, הקבצים שלך יהיו זמינים בקוד ואפשר יהיה לטעון אותם ישירות למערכת.
